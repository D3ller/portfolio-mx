      Vidéos réseaux sociaux

      Colle les liens de tes reels Instagram : ils s’affichent en 9:16 dans le bandeau de la page Simplicicar, dans l’ordre de la liste.

      Comment récupérer le lien d’un reel ?
      1. Sur le téléphone : ouvre le reel → touche l’avion en papier (Partager) → Copier le lien.
      2. Sur l’ordinateur : ouvre le reel sur instagram.com → copie l’adresse dans la barre du navigateur (elle contient /reel/).
      3. Tout un compte d’un coup : ouvre l’onglet Reels du profil sur instagram.com, fais un clic droit sur chaque vignette → Copier l’adresse du lien, et colle-les tous ci-dessous.

      Le reel doit être public. La vignette est facultative mais conseillée : Instagram ne la fournit pas automatiquement (fais une capture, ou ajoute le fichier vidéo : la vignette sera extraite toute seule).
